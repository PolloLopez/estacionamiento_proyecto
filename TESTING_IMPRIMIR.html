Flujo financiero completo

El flujo completo de principio a fin:
  1. Conductor activa estacionamiento → saldo se debita
  2. Vendedor cobra estacionamiento en persona → saldo_operativo sube
  3. Vendedor cierra caja → CierreCaja creado
  4. Admin certifica el cierre
  5. Admin crea rendición con los cierres certificados → LiquidacionComision generada automáticamente
  6. Tesorero valida la rendición
  7. Tesorero deposita la comisión del vendedor (con comprobante)
  8. Vendedor certifica el recibo y adjunta factura
  • Flujo financiero completo ejecutado sin errores de punta a punta
  • Zona libre de punta a punta: mapa → GPS conductor → cascada manual → pago público (ninguno genera cobro)
  • Infracción de punta a punta: inspector labró → conductor impugnó → admin respondió → conductor pagó → estado = pagada
  • Dark mode: todos los paneles se ven correctamente (sin textos ilegibles)
  • Mobile (Chrome Android): inspectores y conductores — pantalla chica, touch funciona
  • Sin errores 500 en ningún flujo (verificar Sentry / logs Railway al final)
